# 项目概述

本文档详细介绍 AgentScope-Java 的整体架构、模块划分和技术选型。

## 1. 项目定位

### 1.1 AgentScope-Java 是什么？

AgentScope-Java 是一个 **AI Agent 应用开发框架**，让开发者能够快速构建基于大语言模型（LLM）的智能应用。

**核心价值**：
- 🚀 **快速开发**：几行代码就能创建一个 AI Agent
- 🔧 **工具集成**：轻松让 AI 调用各种工具
- 🧠 **记忆管理**：内置对话记忆和长期记忆
- 🔄 **多 Agent 协作**：支持多个 AI 协同工作

### 1.2 适用场景

| 场景 | 描述 |
|------|------|
| 智能客服 | 自动回答用户问题，查询订单，处理投诉 |
| 代码助手 | 帮助写代码、调试、解释代码 |
| 数据分析 | 自动分析数据，生成报告 |
| 自动化办公 | 处理邮件、日程安排、文档处理 |
| 知识问答 | 基于 RAG 的企业知识库问答 |

### 2.2 核心组件说明

#### ReActAgent（核心智能体）

ReActAgent 是框架的核心，采用 **ReAct（Reasoning + Acting）** 模式：

```
┌─────────────────────────────────────────────────────────┐
│                    ReAct 循环                            │
│                                                         │
│    ┌──────────┐      ┌──────────┐      ┌──────────┐   │
│    │ Reasoning │ ──→ │  Acting  │ ──→ │  检查    │   │
│    │  (思考)   │      │  (行动)  │      │ 完成条件 │   │
│    └──────────┘      └──────────┘      └──────────┘   │
│         ↑                                    │         │
│         └────────────────────────────────────┘         │
│                    (循环直到完成)                       │
└─────────────────────────────────────────────────────────┘
```

**工作流程**：
1. **Reasoning（思考）**：AI 分析用户输入，决定下一步做什么
2. **Acting（行动）**：如果需要，调用工具执行具体操作
3. **循环**：直到完成任务或达到最大迭代次数

#### Model（模型层）

负责与大语言模型通信：

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ DashScope   │     │   OpenAI    │     │  Anthropic  │
│ (阿里云)    │     │   (GPT)     │     │  (Claude)   │
└──────┬──────┘     └──────┬──────┘     └──────┬──────┘
       │                   │                   │
       └───────────────────┼───────────────────┘
                           │
                    ┌──────┴──────┐
                    │    Model    │
                    │  Interface  │
                    └─────────────┘
```

#### Tool（工具系统）

让 AI 拥有"双手"：

```java
// 定义工具
@Tool(name = "get_weather", description = "获取天气")
public String getWeather(@ToolParam(name = "city") String city) {
    return "北京：晴天 25°C";
}

// 注册到 Toolkit
Toolkit toolkit = new Toolkit();
toolkit.registerTool(new WeatherTools());

// 配置给 Agent
ReActAgent agent = ReActAgent.builder()
    .toolkit(toolkit)
    .build();
```

#### Memory（记忆系统）

管理对话历史：

```
┌─────────────────────────────────────────────┐
│                  Memory                      │
├─────────────────────────────────────────────┤
│  InMemoryMemory      - 内存存储（默认）      │
│  JsonSession         - JSON 文件持久化       │
│  LongTermMemory      - 长期记忆（向量存储）  │
└─────────────────────────────────────────────┘
```

#### Hook（钩子系统）

在 Agent 执行过程中插入自定义逻辑：

```
执行流程:
  PreReasoningEvent  → 思考前
  ReasoningChunkEvent → 思考流式输出
  PostReasoningEvent → 思考后
  PreActingEvent     → 行动前
  ActingChunkEvent   → 行动流式输出
  PostActingEvent    → 行动后
```

## 3. 模块详解

## 4. 技术选型

### 4.1 为什么选择这些技术？

| 技术 | 选择原因 |
|------|----------|
| Java 17+ | 现代化语法特性（record、sealed class 等） |
| Project Reactor | 异步非阻塞，适合 AI 应用的流式响应 |
| Jackson | 业界标准，性能优秀 |
| Maven | 企业级项目管理，依赖管理完善 |
| Spotless | 自动代码格式化，保证代码风格统一 |

### 4.2 支持的模型

| 模型 | Provider | 特点 |
|------|----------|------|
| Qwen | 阿里云 DashScope | 国内首选，性价比高 |
| GPT-4 | OpenAI | 能力最强 |
| Claude | Anthropic | 长上下文，安全性好 |
| Gemini | Google | 多模态能力强 |

## 5. 数据流

### 5.1 完整的请求处理流程

```
用户输入
    │
    ▼
┌─────────────┐
│  创建 Msg   │  ← 构建消息对象
└──────┬──────┘
       │
       ▼
┌─────────────┐
│   Memory    │  ← 添加到对话历史
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  PreHook    │  ← 执行前置钩子
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  Reasoning  │  ← AI 思考
└──────┬──────┘
       │
       ├─── 需要工具？──→──┐
       │                   │
       │              ┌────┴────┐
       │              │ Acting  │ ← 执行工具
       │              └────┬────┘
       │                   │
       │   ←───────────────┘
       │
       ▼
┌─────────────┐
│  PostHook   │  ← 执行后置钩子
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  返回响应   │
└─────────────┘
```

### 5.2 消息流转

```
Msg（用户消息）
    │
    ├── TextBlock: "今天天气怎么样？"
    │
    ▼
Model（发送给 AI）
    │
    ▼
Msg（AI 响应）
    │
    ├── TextBlock: "让我帮你查一下天气"
    ├── ToolUseBlock: get_weather(city="北京")
    │
    ▼
ToolExecutor（执行工具）
    │
    ▼
ToolResultBlock: "北京今天晴天 25°C"
    │
    ▼
Msg（最终响应）
    │
    └── TextBlock: "北京今天天气晴朗，气温 25°C"
```

## 7. 设计原则

### 7.1 SOLID 原则应用

- **S (单一职责)**：每个类只负责一件事
  - `Model` 只负责模型调用
  - `Memory` 只负责记忆存储
  - `Tool` 只负责工具执行

- **O (开闭原则)**：对扩展开放，对修改关闭
  - 新增模型：实现 `Model` 接口
  - 新增工具：添加 `@Tool` 注解方法
  - 新增钩子：实现 `Hook` 接口

- **L (里氏替换)**：子类可以替换父类
  - 任何 `Memory` 实现都可以互换
  - 任何 `Model` 实现都可以互换

- **I (接口隔离)**：接口最小化
  - `Model` 接口只有 2 个方法
  - `Memory` 接口只有 4 个方法

- **D (依赖倒置)**：依赖抽象而非具体
  - Agent 依赖 `Model` 接口，不依赖具体实现
